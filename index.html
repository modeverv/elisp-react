elisp-react

React, written in Emacs Lisp. GNU Emacs runs in the page as WebAssembly (wasmacs); components, state and the reconciler are Emacs Lisp; JavaScript only applies DOM operations.

  • Counter: a component with state (counter.el)
  • Counters: state in a parent, props down, events up, a list, a controlled input (counters.el)

Library: react.el · Host: elisp-react.js · GitHub

The first visit of an example downloads Emacs, about 150 MB.
