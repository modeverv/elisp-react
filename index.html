elisp-react

React, written in Emacs Lisp. GNU Emacs runs in the page as WebAssembly (wasmacs); components, state and the reconciler are Emacs Lisp; JavaScript only applies DOM operations.

A page is an HTML file with .el files next to it: no build step, no bundler. With a native Emacs as the web server, a whole application (server, page, shared code, the data they exchange) is Emacs Lisp.

  • Counter: a component with state (counter.el)
  • Counters: state in a parent, props down, events up, a list, a controlled input (counters.el)
  • TODO list: the jsx macro, keyed rows that keep their own state, filters, reordering, saved in localStorage (todo.el)
  • Time and requests: an interval, a timeout, fetch with loading and error states (async.el)
  • Emacs on both ends: a native Emacs is the web server and keeps the data, they exchange Lisp (app.el, server.el, notes.el). It needs its server: run examples/server/run.sh in a checkout.

Library: react.el · Host: elisp-react.js · GitHub
